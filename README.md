# 闪决 · SNAP

一个为手机设计的反应类挑战小游戏：屏幕给出一条指令，在时间条流干之前，点中对的格子。

## 玩法

- 每回合出现一条指令，例如「点出红色」「点出最大的数」「点出这个形状」「点出不同的那个」。
- 尽快点中正确的格子得分，越快分越高；连续答对累积连击倍率。
- 答错或超时扣一条命，命光进入结算。越往后选项越多、时间越短。

## 试玩

直接用浏览器打开 [`dist/index.html`](dist/index.html) 即可，无需构建。

## 结构

- `dist/` —— 游戏本体（`index.html` / `styles.css` / `game.js`），静态托管目录。
